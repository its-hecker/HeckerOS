# Caracal Dawn v1

Original HeckerOS anime wallpaper assets, generated with the built-in Image Generation tool on 2026-10-28. Both layers are 860×1828. Foreground is real RGBA, with transparent space above and around the character. Background is an opaque scenery layer. Neither layer contains time, widgets, app icons, or a phone frame.

`DefaultAppearance` composites the same aligned pair at runtime for the home/lock wallpaper and stores bounded 1600px copies in device-protected, per-user depth storage. SystemUI renders the translucent live clock between the matching layers. Clock digits/date are never baked into the wallpaper.
