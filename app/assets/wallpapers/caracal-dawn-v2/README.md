# Caracal Dawn v2

Original HeckerOS anime wallpaper assets. The foreground was edited with the built-in Image Generation tool on 2026-10-29 to use modest full-coverage clothing and more clock space. The original dawn scenery from 2026-10-28 is retained. Both layers are 860×1828. Foreground is real RGBA, with transparent space above and around the adult character. Background is an opaque scenery layer. Neither layer contains time, widgets, app icons, or a phone frame.

`DefaultAppearance` composites the aligned pair for the native wallpaper and stores bounded 1600px copies in device-protected, per-user depth storage. SystemUI and Hecker Launcher render matching layers around their clocks. Clock digits/date are never baked into the wallpaper.

## Foreground prompt

Fully closed high-neck opaque navy undershirt, relaxed pale-blue/navy jacket and restrained copper trim; full chest coverage, no cutouts or bare midriff. Softer natural expression. Slightly smaller head, lower/right placement and clear upper-left clock space, with only a small ear/hair overlap. Preserve the tall 860×1828 canvas, blue rim/peach front light and real transparent alpha. No scenery, time, digits, UI, writing, logo or watermark.
